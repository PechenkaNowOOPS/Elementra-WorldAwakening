# Elementra — World Awakening

**Статус репозитория: DOCUMENTATION READY (не готовый плагин).**  
**Платформа целевого сервера:** Minecraft Java Edition, Purpur/Paper 26.2, Java 25.  
**Цель:** подготовить основу отдельной системы «Пробуждение мира» для последующей разработки через Codex.

## Суть системы

Четыре уникальные Печати (`FIRE`, `WATER`, `EARTH`, `AIR`) охраняют четыре тематических босса. Каждая сохранённая активация Печати повышает общесерверную стадию угрозы на единицу (0–4). Количество активированных Печатей определяет силу разрешённых мобов, а конкретные стихии — доступные стихийные варианты. Незер открывается лишь после всех четырёх подтверждённых активаций.

Прохождение Печатей не требует определённого народа и может быть в любом порядке. Приоритет у региональной сложности и доступности базового выживания для новичков. Числовые значения в документации — **предварительный баланс для плейтестов**, не утверждённая реализация.

## Подготовка к GitHub/Codex

Репозиторий создан локально в Git с веткой `main` и первым коммитом. Чтобы пользоваться **облачным Codex**, опубликуйте его на GitHub в **новом приватном репозитории** (например, `Elementra-WorldAwakening`) и предоставьте Codex доступ к нему через настройку подключения репозиториев.

```bash
# Выполнять внутри распакованной папки, после создания пустого репозитория на GitHub
# Замените OWNER, если профиль GitHub отличается.
git remote add origin https://github.com/OWNER/Elementra-WorldAwakening.git
git push -u origin main
```

Общий проект Elementra и существующие репозитории не меняются от этих команд.
