# Архитектура World Awakening

**Статус:** проектная архитектура; не реализовано и не подтверждено на сервере.

## Ответственность

- **NetherSeals:** алтари, рейды, хранители, результаты попыток, право активации, установка Ядра, стойкий факт активации Печати.
- **WorldProgression:** единственный источник глобального состояния мира; потребление подтверждённых активаций; неизменяемый снимок `activeSealIds`, `threatStage`; правило открытия Незера.
- **MobDifficulty:** уровень угрозы при разрешённом появлении моба; региональный коэффициент; стихийные варианты; сохранение отметки уже применённого профиля.
- **Regions:** классификация защищённых и опасных зон.
- **Dungeons / HuntingGrounds / FourNations:** собственные правила и данные без неявного изменения от пробуждения мира.

## События и идемпотентность

Победа над боссом не усиливает мир. Только надёжно сохранённая установка Ядра публикует событие с `sealId`, `operationId`, ревизией и датой. WorldProgression повторно проверяет уникальность и корректность `sealId`, сохраняет свою ревизию и публикует новый снимок. При сбое доставка повторяется без второго применения.

## Порядок обработки моба

1. Проверить разрешение на усиление и исключения (защита, питомцы, охотничьи существа, арены, специальные спавны).
2. Получить профиль региона и атомарный снимок мировой прогрессии.
3. Вычислить категорию и характеристики из балансового конфигурационного профиля.
4. Выбрать стихийную способность только из активированных Печатей.
5. Нанести атрибуты один раз и сохранить метку профиля в PDC.

Запрещены синхронные обращения к SQL при спавне, полный обход мобов каждый тик и ретроактивное усиление существ во время боя.

## Сохранение и отказоустойчивость

При ошибочной конфигурации или неполном глобальном состоянии Незер остаётся закрытым (**fail-closed**). Для каждой из 16 комбинаций четырёх стихий должны быть тесты подсчёта стадии и условий открытия Незера.
