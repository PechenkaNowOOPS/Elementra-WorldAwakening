# Реестр решений World Awakening

## Утверждено владельцем проекта

- Четыре обязательные Печати: Огонь, Вода, Земля и Воздух.
- Каждую Печать охраняет соответствующий стихии босс.
- Стихии соответствуют специализациям четырёх народов: Вулканцы, Аквари, Горны, Аэриды. Выбор народа не является условием участия в рейде.
- Количество активированных Печатей определяет общую стадию усиления мобов; конкретные активированные стихии определяют доступные стихийные свойства.
- Сохранённая активация Печати, а не убийство босса, меняет мировое состояние.
- Незер открывается после четырёх Печатей; порядок прохождения свободный.

## Тестовое / предложено, не окончательный баланс

- HP: 0 / +7 / +13 / +19 / +25% на стадиях 0–4.
- Урон: 0 / +4 / +8 / +12 / +15%.
- Региональные доли глобального усиления: 0% (защищённые зоны), 35% (поселенческий пояс), 75% (средние регионы), 100% (опасные регионы).
- Стихийные варианты и новые боевые способности; дополнительные материалы и трофеи.

## Не утверждено

- Имена, точные характеристики и фазы четырёх боссов.
- Таблицы лута, частоты элит, конкретные правила зон и итоговые коэффициенты.
- Расширение объёма ЗБТ за пределы стабилизации ядра.
